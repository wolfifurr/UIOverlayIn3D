This tool displays CanvasLayer from your scene onto the viewport to preview your UI in 3D space. It is not interactable, only for preview.

Tested on Godot 4.7.2 and should work on Godot 4.2 and newer.

If the Godot development team finds this plugin useful for inclusion in the core engine, you have my full permission to integrate it without needing to contact me and with or without crediting me. 
I just think it should be already in core engine :)
